# 비상업·상업 이용 사례 비교

**미확정 정책 검토표.** SDK 열은 PolyForm 후보를 원문 그대로 채택할 경우의 예비 해석이고, API 열은 사용자가 제시한 방향을 구체화한 제안이다. 현재 허가를 발급하지 않는다. 모든 행에 원 공급자 데이터 조건이 별도로 적용된다. 명칭보다 실제 이용 목적·주체·전달 대상·수익/사업 관계를 본다. 불명확한 법적 경계는 확정 판정 대신 확인 필요로 표시했다.

| 사례 | SDK 표준 후보 기준의 예비 해석 | 제안하는 API 운영 기준 | 추가 확인 |
|---|---|---|---|
| 개인이 무광고 취미 전파 대시보드 운영 | 비상업 목적에 부합 | 한도·IonoFlux/공급자 표시를 지켜 허용하는 안 | 유료 배포·광고로 전환 시 재판단 |
| 개인이 노트북으로 독학, 결과 비공개 | 비상업 목적에 부합 | 허용하는 안, 내부 README/노트북에 출처 | 공개 발표 의무는 없음 |
| 기업이 신제품·고객 서비스용 내부 R&D | 상업 적용이 예정된 연구라 표준 허용으로 보지 않는 해석 | 사전 서면 허가 | 비공개·매출전·PoC라는 이유로 무료 허용 아님 |
| 기업이 사업과 무관한 공개 기초 연구 | 사실관계·목적에 따라 판단 필요 | 심사 대상으로 제안, 자동 허용/금지 단정 안 함 | 기업이라는 이유만으로 모든 비상업 목적을 부정하지 않음 |
| 수익화된 웹사이트·유료 앱·구독 API·SaaS | 일반 영리 사업이면 별도 코드 허가 필요 해석 | 사전 서면 허가 | SDK와 API 허가 범위 각각 확인 |
| 무료 프로젝트지만 광고·제휴판매 수익 있음 | 영리 목적이면 별도 허가, 예외 기관 여부 별도 | 사전 허가 대상으로 제안 | 무료 다운로드=비상업 아님, 소액/비용 충당 면제는 미정 |
| 자발적 기부만 받고 개인 서버 비용 충당 | 목적·대가·수익 약정 확인 필요 | 사례 확인 필요 | 광고 노출 약정·유료 혜택이면 일반 기부와 구분 |
| 대학 수업·기초 연구 | 교육기관 조항상 허용 해석 | 비상업 교육/연구 허용하는 안 | 데이터의 NC 목적 판단은 별개 |
| 대학의 기업 후원·의무가 있는 연구 | 기관 조항 때문에 후원/의무만으로 SDK 금지 아님 | 사업 납품·독점 성과/상업 활용은 별도심사안 | 표준 SDK 허용과 API 심사 범위의 차이를 승인해야 함 |
| 대학이 직접 수행하는 기술이전·유료 활동 | 기관 조항의 넓은 적용 범위를 법률 검토 | 수익 목적 API 활용은 사전 허가 제안 | 별도 대학 영리 자회사·스핀오프는 같은 기관으로 자동 취급 안 함 |
| 자선·공공연구·환경보호 기관의 공익 프로젝트 | 원문 열거기관에 해당하는지 확인 후 허용 해석 | 비상업 공익 활동 허용하는 안 | 단순 “비영리 법인” 등록만으로 모든 기관 예외 단정 금지 |
| 비영리 단체의 유료 보고서·고객 납품 | 적격 기관이면 SDK 조항상 허용 가능, 기관 성격 확인 | 영리 활동 API 활용은 사전 허가 제안 | 기관 지위와 개별 서비스 목적을 분리 |
| 논문을 유료 학술지에 출판 | 출판사 유료성만으로 연구자의 SDK 목적을 상업으로 단정 안 함 | 실제 연구/계약 목적 확인 | 공급자의 논문 인용·데이터 재배포 조건 확인 |
| SDK 포함 Python 패키지/앱 재배포 | 허용 목적과 사본 고지 전달 확인 | API 활용 시 별도 출처·접속 조건 | 코드 사본 배포와 단순 데이터 결과 공개 구분 |

표준 후보 열은 [원문 목적·기관 조항](https://polyformproject.org/licenses/noncommercial/1.0.0)에 따른 검토 해석이다. API 열은 그 원문을 재서술한 법적 결론이 아니라 별도 서비스 정책 초안이다. 표준이 명시적으로 허용하는 기관 이용을 README에서 임의로 금지해 놓고 표준 라이선스라고 부르지 않는다.

상업 계약으로 허용할 수 있는 것은 IonoFlux가 권리를 가진 범위다. SILSO·WSPR 등 제3자 조건은 독립 확인하며, SDK 허가 또는 API 과금만으로 공급자 NC가 해제되지 않는다. 공급자별 재허가 가능성을 확인하지 못한 경우에는 해당 데이터의 상업 제공을 약속하지 않는다.
